# Career Card Visual Lab — Pass 5: Table composition study

Owner-directed work, 2026-10-10. The owner rejected Pass 4's subtle rarity
progression. They approved proving one event across all four tiers before
applying that design language to the other event families. This pass changes
only Table specimens in the isolated lab. Other families remain clearly labelled
Pass 04 references, not newly reviewed designs.

## Built

The card dimensions, cabinet, drawer and physical inspection are retained.
Table progression now changes print coverage, composition, stock and artwork:

- Common: preserved cream invitation, forest-green keyline and quiet oval table.
- Uncommon: green stock, mint/cream frame and cream prize stub; a new colour-print
  illustration with larger chip stacks and a wider table composition.
- Rare: blue stock with silver construction; a larger authored scene, foreground
  playing cards overlapping the printed picture frame and a silver prize plate.
- Legendary: a bespoke full-face velvet casino scene with a warm lamp, columns,
  table, foreground cards and chips. Two-line spectral title, prismatic rim,
  engraved foil pattern and a quiet prize plaque are integrated into that scene.

The four Table prizes remain $300 / $600 / $1,500 / $5,000, illustrative fixtures.
The same finite pickup/replay finishes, bounded pointer/touch tilt, focus return
and Reduced Motion apply. MARKS hides visible rarity letters and edition labels
without changing card geometry. Production rules, economy and saves are not
connected.

## Critical visual assessment

Acceptance criteria: at drawer size the tiers must differ while stationary;
Legendary must have an exclusive composition rather than only additional shine;
titles/prizes remain legible; artwork stays pixel-authored and consistent with
burgundy velvet, green felt, cream cards, mustard light and hard physical edges.

The initial render was corrected in two places: a descriptor crowded the
Legendary lamp/title and was removed; a Rare frame line painted over foreground
cards and was moved behind the illustration. These were assessed in enlarged
inspection and drawer views.

Final evidence includes a 390px drawer with motion disabled and marks hidden,
and a grayscale view additionally hiding prize amounts. The four different
stock/value fields, framed versus enlarged versus full-face compositions, and
foreground overlaps remain visible. The Legendary has the strongest visual
presence through its own scene and layout. It does not depend on motion to
separate it from Uncommon. Common stays deliberately pleasing and restrained.

Agent assessment: this Table study passes the stated visual criteria and is
ready for owner review. This is a design judgement, not a measured collector
preference study or owner approval. Actual iPhone feel/120Hz performance remains
unverified; the other three event families are not promoted by this assessment.
