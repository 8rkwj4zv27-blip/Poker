The Table Pattern Book

One finish per job. When the same kind of part appears on two screens it is built the same way: same material, glow, depth, motion and sound. What it says and where it sits stay free. New UI takes its parts from this book; a genuinely new part is signed off and added here first.

CRT screens

Any screen that shows information which changes while the machine runs. Signed off 24 September 2026: blue record glass, flicker and blink, four ink meanings.

PartRuleWhere it lives
Use itAdd machine-crt to the screen element. Keep your own size, padding and layout.css/machine-crt.css
GlassBlue-tinted near-black tube, soft recessed bezel, vignette, static scanlines, faint halo. Never restyle the glass per screen.#app .machine-crt
TextNo bloom or text shadow. Mechanical-number reels inside a CRT keep their own treatment.same file
IdleFaint stepped flicker, 5.8s cycle.--crt-flicker
ChangeStatic-burst blink (0.23s) whenever the text changes. Automatic; call nothing. A screen whose change is shown by a number wheel sets data-crt-blink="off".js/machine-crt.js, --crt-blink
InkDeclare the screen's meaning with data-ink: none (ordinary machine info) · live (live table info) · money · danger. Every character on the glass takes that ink; money reels inside any screen read as money. Fixed across colour themes. Never colour CRT text locally.--crt-ink-* in the same file
CaptionsOne size (7px), spacing and dimmer ink for the small labels on every screen.--crt-label, --crt-ink-label
CellsThe glass is one surface: no inner panels. Multi-cell screens divide it with one thin rule.--crt-rule
Reduced MotionNo flicker, no blink.same file
